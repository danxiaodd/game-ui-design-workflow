# 视觉资料摘要（示例）

权威来源：[Factory v2 GDD](../factory-v2-shop/gdd.md)。本摘要仅提炼视觉需求，不替代原策划。

| 结论 | 性质 | 依据/理由 |
|---|---|---|
| 2D 欧美卡通生存 Roguelike 商店 | 已确定 | GDD「一句话定位」 |
| 战斗结束后筛选购买并准备下一轮 | 已确定 | GDD「核心循环」 |
| 商品与价格需快速识别，主购买操作明显 | 推导 | 服务战斗间隙补给的任务 |
| 图标用清晰轮廓、简化材质和有限高光 | 视觉建议 | 便于小尺寸阅读，待用户选择 |
| 平台/方向/画布采用当前项目已批准值 | 尚需读取项目资料 | GDD 本身没有规定；本示例不伪造已知尺寸 |
| 独立主城、家业建筑和完整角色体系 | 未规定/当前不适用 | 不为了填方向案而新增系统 |
